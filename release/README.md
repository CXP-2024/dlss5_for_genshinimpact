# Release files

These are the small files that can be shared directly under the documented licenses.

- `fps-unlocker/`: `unlockfps_nc.exe` and `UnlockerStub.dll`.
- `configs/`: the DX11 FSR2 bridge runtime and its verified configuration.
- `custom-bridge/`: the locally rebuilt DLSS5 DX11 bridge add-on.

The NVIDIA DLLs, ReShade runtime, OptiScaler runtime and RenoDX DLSS5 add-on are
intentionally excluded. See `docs/REDISTRIBUTION.md`.
